# Site pessoal para a atividade WordPress

Site pessoal de Danilo Firme, criado com base no modelo de conteúdo do exercício Homework #10.

**Atenção:** esta pasta contém uma *prévia estática* hospedada via GitHub Pages e não é, por si só, uma instalação WordPress nem um export do plugin Simply Static. Para a entrega acadêmica que exige WordPress, é preciso criar/publicar o site no WordPress ou exportar uma instalação WordPress com Simply Static.

Não inclui lista de projetos, conforme solicitado.

Página de prévia: https://danilofirme.github.io/site-pessoal-wordpress/

O portfólio original na raiz não foi alterado.
